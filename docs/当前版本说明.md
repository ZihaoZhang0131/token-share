# 当前版本说明

核对日期：2026-11-06。本文件说明当前本地代码中的像素风重构，不代表该版本已推送 GitHub 或部署到生产。

## 当前界面

采用暖色农场菜单风格：浅色天空与移动白云背景（无草地或树木）、居中羊皮纸主窗口、棕色圆角木框、圆角卡片和顶部图标 Tab。Tab 与统计卡加入柔和蓝、鼠尾草绿、杏橙和淡紫分区，图表与模型面板采用浅冷色，文字保持深色；数据条保留语义颜色，成功与失败同时用文字标识。重复解释文字已精简，教程的接口范围与排错默认折叠。标题使用本地托管的 Fusion Pixel 中文像素字体，正文保留清晰的系统字体，代码使用等宽字体。旧 Open Ledger 深色主题和固定侧栏已被替换。

布局以桌面网页为主，主窗口最大宽度约 1080px，1440px 桌面两侧各留 180px；1280px 和 1024px 视口两侧分别约留 138px 和 72px 安全边距。宽桌面统计卡四列、趋势图并排，较窄容器自动换行。12 朵白云分六组覆盖视口高度，宽约 94–212px，大小错落，以纯 CSS 按 250–340 秒周期向右移动，减少动态效果设置下静止。窄窗口通过卡片换行、Tab 横向滚动等保持可用。主窗口不支持拖拽或缩放。具体设计与产品约束见 `DESIGN.md`、`PRODUCT.md`。

## 页面与行为

| 场景 | 当前实现 |
|---|---|
| 未登录 | 访客版用户控制台，私有数值显示 `—`，身份相关动作打开登录弹窗 |
| 首次登录 | `PasswordGate` 要求修改临时密码 |
| 管理员 | 总览、上游、模型、用户、调用日志、审计日志六个 Tab |
| 普通用户 | 我的用量、访问 Key、接入指南三个 Tab |
| Key 创建 | 明文只在创建成功时展示一次，关闭后不再读取 |
| 登录与编辑 | 使用公共像素风弹窗，输入时不重复抢焦点，保留键盘导航和关闭后焦点恢复 |

访客界面不代表放开权限。实际读写仍由 Session、角色、CSRF 和 Bearer Key 控制。

## 新增统计与单位

管理员和普通用户使用共用的用量手账组件，可切换本月、近 7 天和近 30 天。管理员总览展示 Token、调用次数、成功率、平均完整请求耗时、每日输入/输出与成功/失败图表，以及模型和用户消耗排行。用户页将固定的本月额度与可切换期间的趋势分开，展示模型消耗占比。

统计来自新增 `/api/admin/analytics` 和 `/api/me/analytics`，按北京时间自然日聚合完整用量账本，不从最近 200 条日志推算。排行展示前五项与“其他”。无请求时成功率及耗时显示 `—`，无消费时使用真实空状态；错误后保留并标明上次成功的数据，可重新加载。图表支持悬停和键盘聚焦查看精确数值。

消耗、余额、图表与日志统一显示 M，`1 M = 1,000,000 Token`，最多三位小数；非零小值显示 `<0.001 M`。额度、TPM 和最大输出的配置输入仍使用整数 Token，旁边显示 M 换算提示。后端存储、配额和结算规则没有变化，无数据库迁移。

统计只覆盖已入账请求；请求平均耗时包含完整流式时间，不是首 Token 延迟，也不代表上游服务可用率。

## 接入指南

指南分为聊天 API、编码 API、CC Switch + Codex 三个入口，按准备 Key、选择授权模型、配置、验证和排错组织。当前站点的 Base URL、公开模型名和配置片段支持独立复制；未登录或未获对应模型授权时不生成看似可用的配置。

CC Switch 教程介绍原生 Responses 直连、自定义供应商、公开模型映射、固定推理档位和重启验证，并分别说明 CLI 与桌面端的配置目录、凭证和登录保留差异。提供 macOS/Linux、Windows PowerShell 示例及常见错误排查。客户端兼容性受具体版本影响，文档核对不等同于真实上游与全部客户端版本验证。

## 主要代码入口

- `frontend/src/App.tsx`：Session 恢复、首次改密与角色分流。
- `frontend/src/GameFrame.tsx`、`PixelIcon.tsx`、`styles.css`：公共菜单窗口与像素视觉；页面业务仍在 `AdminConsole.tsx`、`UserConsole.tsx`、`Login.tsx`。
- `frontend/src/Analytics.tsx`、`formatTokens.ts`：期间统计、SVG 图表、排行和 M 单位。
- `frontend/src/IntegrationGuide.tsx`、`guideSnippets.ts`：步骤式接入指南及动态配置模板。
- `frontend/src/components.tsx`：公共弹窗及焦点修复。
- `app/analytics.py`：账本聚合；`app/schemas.py` 定义返回结构。

`.impeccable/` 中的旧设计和截图是历史资料，不能作为本轮视觉验收证据。`frontend/dist/` 为本地构建产物，生产镜像由 Dockerfile 重新构建。

## 验证与发布边界

本轮后端已通过 87 项 Pytest 测试和 Ruff，包括新增统计的时间边界、用户隔离、空数据、超过 200 条记录和排行汇总。PostgreSQL 查询已做方言编译检查；自动化统计测试使用临时 SQLite，未据此声称完成真实 PostgreSQL 或生产验证。

前端 8 项单元测试、16 项 Chrome Playwright 浏览器测试、TypeScript 检查及生产构建通过。截图检查覆盖 1440px、1280px、1024px；包含管理员各 Tab、用户用量、Key、接入指南、访客和登录，以及长模型名、长邮箱、零额度和独立接口失败。

另外在临时 SQLite 与本地 FastAPI + Vite 环境执行了真实浏览器登录、首次改密、空账本统计、管理员六个 Tab 与退出流程，无浏览器运行错误。图表截图使用测试夹具，仅用于视觉验收；未使用线上账号或真实上游 Key，未改写个人 Codex/CC Switch 配置。截图输出到本地忽略目录 artifacts/。

本轮交付默认是本地代码，不执行生产部署。上线仍遵循 [日常迭代与线上发布指南](日常迭代与线上发布指南.md)。独立运维事项如首次 TLS 脚本环境变量优先级、备份管道检查不在此次 UI 改造范围。
